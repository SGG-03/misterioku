MISTERIOKU — paquete PWA inicial
=================================
Incluye:
- index.html: demo jugable
- manifest.webmanifest: identidad instalable de la app
- sw.js: caché básica para abrirla sin conexión después de la primera carga
- icons/: iconos provisionales

IMPORTANTE:
Este paquete todavía NO es una app lista para subir a Google Play o App Store.
Primero hay que publicarlo en una URL HTTPS (por ejemplo, GitHub Pages), probarlo en móviles y completar el juego.
No introduzcas contraseñas ni datos personales en páginas que no sean las oficiales.
